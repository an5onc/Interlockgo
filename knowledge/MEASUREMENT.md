# Measurement plan

Establish a 30-day baseline before changing public content, then review monthly. Website traffic alone is not success.

| Measure | Source | Baseline and review rule |
| --- | --- | --- |
| Calls by destination number | Shop/provider call reporting | Separate the shop line from provider enrollment/tracking and support lines. |
| Text conversations | Approved messaging platform | Count conversations, not message volume; never export message bodies here. |
| Appointment starts and completions | Scheduling/operations system | Track started, scheduled, attended, canceled, and no-show separately. |
| GBP calls and direction requests | Google Business Profile | Monthly; annotate listing or hours changes. |
| Branded/non-branded queries | Search Console | Monthly query groups and landing pages. |
| Generative-AI visibility | Search Console when available | Treat as a directional report, not a complete attribution source. |
| ChatGPT referrals | Analytics | Use `utm_source=chatgpt.com` on links InterlockGo controls. |
| Repeat-question volume | De-identified staff tally | Use question IDs only; do not store caller identity or transcripts. |
| Staff answer consistency | Monthly scored sample | Compare answers with the approved register and cited source. |
| Incorrect/unsupported answer rate | Evaluation log | Record the question ID, failure type, and source correction—not customer details. |
| Review compliance | Truth System validator | Percent of approved records reviewed before their next-review date. |
| Stable question-set visibility | Monthly manual test | Use the same customer questions and record whether answers are correct and sourced. |

Recommended funnel: call/text/appointment start -> scheduled appointment -> completed appointment. Keep provider-routed calls separate so a provider tracking number is not mistaken for the shop's direct line.
