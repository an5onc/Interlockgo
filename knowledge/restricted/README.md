# Restricted-data boundary

Do not place restricted data in this repository.

Prohibited examples include raw customer calls or transcripts, names tied to cases, driver-license or DMV identifiers, personalized DMV letters, court records, vehicle identifiers tied to a person, payment-card data (especially card security codes), credentials, secrets, and confidential rate sheets not approved for repository storage.

Store only de-identified question IDs and topic summaries. A future restricted system requires a separately approved privacy, consent, access-control, encryption, audit, and retention design.
